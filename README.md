# 내 말로 증명하다 · 성인·박람회판

AI 시대에 내 생각을 내 말로 증명하는 삼지작법 말하기 연습 앱이에요. 대상은 대학생과 성인이에요. 2027 불교박람회 부스용 박람회 모드가 들어 있어요.

- 청소년판(`prepjoo/balnce5-temple`, 브랜치 `youth-v1.0`, 커밋 `5dd68f9`)을 복사해 만들었어요. 청소년판은 고치지 않아요.
- 서버·로그인·결제가 없는 정적 웹(HTML·JS)이에요. 기록은 각자의 브라우저에만 남아요.
- 삼지작법(宗·因·喩)은 진나가 정리한 인명학의 논증 형식이에요. 여는·받치는·답하는 삼지작법은 이를 현대 말하기에 맞게 응용한 것이에요.

## 주소별 화면

| 주소 | 화면 |
| --- | --- |
| `/` | 일반 모드: 짜기 → 말하기 → 재기, 워드댄싱, 다섯 저울, 경험 카드 |
| `/?q=M-07` | 카드 QR: 그 질문의 짜기 화면이 바로 열려요 (M-01~M-18, B-01~B-18) |
| `/?booth=1` | 박람회 모드(부스 태블릿): 체험자 구분 → 질문 공 번호 → 삼지작법 고르기 → 30초 → 채운 저울 n/5 → 결과 QR. 60초 동안 손대지 않으면 처음으로 |
| `/?r=M-09.P.32323` | 부스 결과 QR로 휴대폰에서 여는 결과 화면. 결과 이미지(1080×1920)를 저장해요. 답 문장은 담기지 않아요 |
| `/#origin` | 유래 화면: 진나와 인명학, 종·인·유, '응용' 밝힘, 감수자 |

부스 통계: 박람회 모드 첫 화면의 제목 '내 말로 증명하다'를 빠르게 5번 누르면 통계 화면이 열리고 CSV로 내려받을 수 있어요. 숫자만 태블릿 안에 저장돼요(체험 수, 고른 삼지작법, 채운 저울 평균, 학생·선생님·일반 수, 다시 하기 저울 증가).

## 배포 (Vercel)

1. Vercel에서 **Add New → Project → `prepjoo/expo` Import**
2. Framework Preset `Other`, Output Directory `public` (vercel.json에 이미 들어 있어요)
3. 배포 주소가 나오면 `public/config.js`의 `siteUrl`에 넣어요. 카드·결과 QR에 이 주소가 들어가요.

`public/config.js`

```js
window.EXPO_CONFIG = {
  siteUrl: '',   // 배포 주소
  youthUrl: '',  // 청소년판 앱 주소 → 홈에 '중·고등학생이에요' 연결이 생겨요
  reviewer: ''   // 감수자 이름 → 유래 화면에 표기
};
```

## 질문 고치기 (카드와 앱이 같은 문장)

1. `content/questions.json`만 고쳐요. 한 묶음 = 질문 + 예시 답 네 칸 + 함정 문장 + 함정 이유.
2. `node tools/check.js`: 칸당 40자, 숫자, 예시 80점 이상, 함정 40점 이하, 칸 순서를 바꾸면 점수 하락을 앱 채점기로 검사해요.
3. `node tools/sync.js`: `public/content.js`를 다시 만들어요. 카드 생성기(content.py)도 같은 JSON을 읽게 하면 돼요.

B 묶음(불교 확장팩)은 감수 전 초안이에요.

## 파일

- `public/adult.js` 대상을 '성인(대학생 포함)'으로, 영역 5개(학업·AI, 취업 면접, 일·회의, 관계·대화, 불교·마음)
- `public/expo.js` QR 열기, 박람회 모드, 결과 이미지, 부스 통계, 유래 화면
- `public/sw.js` 오프라인 캐시 (전시장 와이파이가 끊겨도 체험이 돌아가요)
- `public/qrcode.js` QR 생성기 (qrcode-generator 1.4.4, MIT)
- `public/app.js` 청소년판 화면·채점기(scoreAnswer) 그대로, 대상 함수와 연결 부분만 바꿈
